# Fotos do Baú Super Produção 3 Andares

Coloque as fotos nesta pasta com estes nomes (JPG, de preferência quadradas ~1200x1200):

| Arquivo | O que é |
|---|---|
| `01-capa-frente.jpg` | Foto de capa — baú fechado, de frente (usada no topo da página) |
| `02-aberto-andares.jpg` | Aberto, mostrando os 3 andares — **a foto mais importante** |
| `03-detalhe-andar.jpg` | Close de um andar / da bandeja |
| `04-moto.jpg` | Montado na moto |
| `05-traseira.jpg` | Traseira |
| `06-suporte.jpg` | Suporte de fixação |

Se o produto tiver mais de uma cor, crie subpastas (`preto/`, `branco/`) como
já é feito para o baú de 87 litros.
